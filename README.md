# TNPSC Study Hub Android App

Version 1.0 starter project.

## Included
- Home screen
- Group 1, Group 2 & 2A, Group 4
- Study Materials
- Current Affairs
- Jobs link to TNPSC official website
- 3-question working mock quiz
- GitHub Actions workflow to build a debug APK

## Build
Open the project in Android Studio, or push it to GitHub and run:
Actions -> Build TNPSC Study Hub APK -> Run workflow

The workflow uploads `app-debug.apk` as an artifact.
